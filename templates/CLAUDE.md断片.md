## 手抜き番（必ず守ること）

このフォルダは「手抜き番（tenukiban）」で見張っています。作業を終えて「できました」と言う前に、必ず次を実行して通してください。

```
{{CLI}} check
```

- 止まったら、表示された「AIにこう頼んでください」の内容に従って、**コードの方を**直してください。
- 次のことは**しないでください**。手抜き番が見つけて止めます。
  - 試験（テスト）を消す・飛ばす（`.skip` `.only` `xit` など）・数を減らす
  - `package.json` の `test` などの確認の命令を空にする・`echo` や `exit 0` や `|| true` にする
  - `.tenukiban/` の中のファイル（基準）や `tenukiban.config.json` を書き換える・消す
  - `.claude/settings.json` の手抜き番のフックを外す。この段落を消す
  - `node_modules` の中を直接書き換える
  - `.env`・鍵のファイルを git に入れる
  - `tenukiban-allow` の免除コメントを、理由なく足す
- `{{CLI}} accept` は**人だけが使う命令です。AI は実行しないでください。**緩める必要があると思ったら、理由を人に説明して頼んでください。
- 手抜き番が通っても「完璧」「100%安全」とは言わないでください。手抜き番が見つけられるのは一部だけです。直せなかったこと・確かめていないことは、正直に報告してください。
